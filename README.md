## ⭐ 학습 내용

### 머신러닝
- 지도학습 / 비지도학습  
- 예측 모델링 기본기  
- 데이터 전처리 및 평가  
- 하이퍼파라미터 튜닝 실습  

### 딥러닝
- 기본 신경망(NN)  
- CNN 기반 이미지 분류  
- RNN / LSTM 기반 시계열 모델  
- Transformer 구조 기초  

### 데이터 분석
- Pandas, NumPy 기반 데이터 처리  
- 시각화(Matplotlib, Seaborn)  
- EDA(탐색적 데이터 분석)  

### 실습 프로젝트
- Kaggle · Dacon 연습 프로젝트  
- 간단한 개인 분석 프로젝트  
- 모델 비교 실험

## 📂 폴더 구성

```text
/
├─ AE/               # AutoEncoder 등 표현 학습 실습
├─ keras/            # Keras 기반 딥러닝 기초 실습
├─ keras2/           # 추가 Keras 실습 (심화 예제 등)
├─ ml/               # 머신러닝 알고리즘 실습
├─ python/           # 파이썬 기본 문법 실습
├─ python_import/    # 모듈/패키지 import 연습
└─ torch/            # PyTorch 기반 딥러닝 실습
```
